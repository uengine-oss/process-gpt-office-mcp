# 해외사업 현황 보고서 도메인 가이드

이 가이드는 해외사업 현황 보고서("사업현황") 양식의 **작성 패턴과 규칙**을 설명한다.
구체적인 사업 내용은 반드시 참고 자료(reference_text)와 보고서 주제에서 추출하여 작성해야 한다.
이 가이드의 예시를 그대로 복사하지 말 것.

---

## 1. 문서 전체 구조

1페이지 분량의 간결한 현황 보고서이다.

```
제목 표 — [사업명] 사업현황  (표 1행: 제목, 2행: 부서/담당자/연락처)
1. 사업 개요              ← □ 불릿 8개 (key-value 형식)
2. 추진 경과              ← □ 불릿 N개 (날짜순 이력)
3. 사업 의의              ← □ 불릿 3개 (전략적/경제적/기술적)
```

---

## 2. 플레이스홀더 패턴: [대괄호] 치환

이 양식은 `[대괄호]`로 둘러싼 플레이스홀더를 사용한다.

### 핵심 규칙
1. `□` 기호는 불릿이므로 **삭제하지 않고 그대로 유지**한다.
2. `[…]` 안의 텍스트는 **힌트/가이드**이다. 이를 참고하여 참고 자료 기반의 실제 값으로 교체한다.
3. 라벨 부분(예: "발 주 처", "사업위치")과 콜론(`:`)은 **그대로 유지**한다.
4. 라벨의 한글 사이 공백(예: "발 주 처", "사 업 주")도 원본 그대로 유지한다.

### 치환 형식
```
양식:   □ 라벨 : [플레이스홀더]
채움:   □ 라벨 : 참고자료에서 추출한 실제 값
```

---

## 3. 제목 표 (2행 1열 표)

- 1행: `[사업명]`을 참고 자료의 실제 사업명으로 교체 + "사업현황" 유지
- 2행: `[부서명]`, `[성명]`, `[내선번호]`를 참고 자료에서 추출하여 교체. 직급도 포함 가능.

---

## 4. 섹션 1: 사업 개요

□ 불릿 8개의 key-value 항목이다. 각 항목은 **간결하게 1-2줄**로 작성한다.

### 항목별 작성 규칙

| 항목 | 플레이스홀더 | 작성법 |
|------|-------------|--------|
| 발주처 | `[발주처명]` | 정식 기관명 + 약어 |
| 사업위치 | `[국가/지역]` | 국가 + 구체적 지역 |
| 설비용량 | `[MW 등 규모]` | 총 규모 + 단위기 구성 + 기술방식 |
| 사업방식 | `[BOOT/BOT/IPP 등]` | 방식명 + 핵심 계약 조건 |
| Offtaker | `[Offtaker 명]` | 기관명(약어) |
| 사업비 | `[U$ 000 백만]` | 총액 + 자금구조(D:E 비율, 조달원) |
| 사업주 | `[사업주 구성 및 지분율]` | 참여사별 지분율(%) + 출자금액 |
| EPC/O&M | `[EPC 사명/O&M 방식]` | EPC사 + 주기기 공급사 / O&M 자체수행 또는 외주 |

### 작성 원칙
- 모든 값은 **참고 자료에서 추출**한다. 참고 자료에 없으면 보고서 주제에 맞는 합리적인 값을 생성.
- 숫자, 비율, 금액은 구체적으로 (단위 명시).
- 괄호를 활용해 부가 정보를 압축적으로 전달.

---

## 5. 섹션 2: 추진 경과

날짜순 이력을 □ 불릿으로 나열한다.

### 양식 패턴
```
□ 'YY.MM. : 해당 시점의 핵심 이벤트
```

### 작성 규칙
1. **날짜 형식**: `'YY.MM.` (예: `'19.03.`, `'22. 6.`)
2. **시간순 정렬**: 과거 → 최근 순서
3. **항목 수**: 양식에는 3개가 있으나, **참고 자료의 실제 마일스톤 수만큼 늘릴 수 있다** (5-10개 권장)
4. **내용**: 참고 자료에서 추출한 실제 날짜와 이벤트를 간결하게 기술
5. **중요 이벤트에는 부연 설명** 가능 (다음 줄 들여쓰기)

### 주요 마일스톤 유형
- 사업권 획득/입찰
- 주요 계약 체결 (PPA, EPC, 금융 등)
- 투자 심의/이사회 승인
- 금융 종결 (Financial Close)
- 착공/준공
- 상업운전 개시 (COD)

---

## 6. 섹션 3: 사업 의의

□ 불릿 3개로 전략적/경제적/기술적 의의를 각각 1-2문장으로 작성한다.

### 3가지 관점
```
□ [전략적 의의] — 참여 구조, 파트너십, 시장 진출 관점
□ [경제적 의의] — 수익 안정성, 계약 구조, 리스크 관점
□ [기술적·환경적 의의] — 적용 기술, 환경 기준, 효율 관점
```

### 작성 원칙
- 각 □는 **독립적인 관점**(전략/경제/기술)에서 서술
- **한 문장**으로 핵심 의의를 함축적으로 표현
- 참고 자료의 사업 특성을 반영하여 구체적으로 작성

---

## 7. 작성 톤과 수준

### 문체
- **"~임", "~함", "~있음"** 체 사용 (경어체 아님)
- 간결하고 사실 중심의 보고서 문체

### 분량
- 전체 1페이지 (A4 가로)
- 사업 개요: 각 항목 1줄 (복잡한 항목은 2줄까지)
- 추진 경과: 항목당 1줄 (부연 필요 시 들여쓰기 2줄까지)
- 사업 의의: 각 항목 1-2줄

### 전문 용어 (적극 활용)
- 사업방식: BOOT, BOT, BOO, IPP, CCGT
- 계약: PPA(전력판매계약), EPC, O&M, FSA(연료공급계약)
- 금융: D:E(부채비율), Financial Close, 수은(한국수출입은행), 무보(무역보험공사)
- 기술: USC(초초임계), SC(초임계), CCGT(복합화력)
- 지표: MW, GW, U$(미국달러), COD(상업운전개시)

---

## 8. 각주(Footnote) 활용

해외사업 보고서에는 현지 기관/기업의 **약어나 전문용어**가 자주 등장한다. 독자의 이해를 위해 각주를 적극 활용한다.

### 마커 형식
```
[FN:본문에 표시할 텍스트|각주 설명]
```

### 각주 대상
- 현지 기관/기업 약어 (본문에 처음 등장할 때)
- 현지 기업명 (독자가 모를 수 있는 기업)
- 전문 용어/계약 약어 (본문에 처음 등장할 때)

### 사용 예시 (형식만 참고, 내용은 참고 자료에서 추출할 것)
```
□ 사 업 주 : A사(지분%), [FN:약어|정식명칭: 간단한 설명](지분%), [FN:약어2|정식명칭2: 간단한 설명](지분%)
□ EPC/O&M : 시공사+[FN:약어|정식명칭: 간단한 설명]
```

### 원칙
- **같은 약어는 첫 등장 시에만** 각주를 달고, 이후에는 생략
- 각주 설명은 **한 줄 이내**로 간결하게
- 널리 알려진 약어(MW, USD 등)에는 각주 불필요

---

## 9. 중요: 참고 자료 활용 원칙

**이 가이드의 예시 문구를 그대로 사용하지 말 것.** 반드시 아래 순서로 내용을 결정한다:

1. **참고 자료(reference_text)가 있으면** → 참고 자료에서 사업명, 수치, 날짜, 기관명 등을 추출하여 사용
2. **보고서 주제(report_topic)와 설명(report_description)** → 사업의 맥락과 방향을 반영
3. 위 두 가지에 없는 정보만 합리적으로 추론하여 생성
