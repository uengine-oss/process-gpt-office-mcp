# 정부사업 제안서 (AI바우처 사업계획서) 도메인 가이드

이 가이드는 정부사업 제안서(AI바우처, R&D 과제, 사업계획서 등)를 채울 때 적용한다.
실제 선정된 제안서를 분석하여 작성되었으므로, 이 가이드의 패턴과 분량을 충실히 따라야 한다.

---

## 1. 문서 전체 구조

이 제안서는 아래 대섹션으로 구성된다. 각 섹션은 **독립적**이며, 다른 섹션의 마커에 다른 섹션 내용을 넣으면 안 된다.

```
표지 — 과제명, 기관명, 대표자, 사업비 등 (표 형태)
기관현황 및 인력현황 — 수요기업/공급기업 비교 테이블
목차 — 자동 생성 영역 (큰 셀 하나, 목차 텍스트)
요약서-1 — 산업분야 현황, 과제, AI솔루션 요약 (표)
요약서-2 — 12개 항목 요약 (표)
Ⅰ. 개요
  1. 추진배경                    ← 패턴 A (마커)
  2. 목적 및 필요성              ← 패턴 A (마커)
  3. 시장 현황 / 시장 동향       ← 패턴 B (소제목+작성요령+빈본문)
  4. 기업 현황                   ← 패턴 B (소제목+작성요령+빈본문)
Ⅱ. 추진 목표
  1. 최종 목표                   ← 패턴 B + 테이블
  2. 성과목표 및 성능지표         ← 테이블 중심
Ⅲ. 컨소시엄 구성 및 역할
  1. 컨소시엄 구성/역할           ← 패턴 A + 테이블
  2. 기관별 과제 수행 역량         ← 패턴 B (가~라 소항목)
Ⅳ. 세부 추진 계획
  1. 사업 개요 (비즈니스모델, 전략, 혁신성)  ← 패턴 A (마커)
  2. 사업 추진 계획 및 방법 (가~자)          ← 패턴 A + B 혼합
Ⅴ. 사업 활성화 및 사후 운영
  1. 사업 활성화/홍보 계획        ← 패턴 A (마커)
  2. 사후 사업계획               ← 패턴 A (마커)
  3. 기대성과 및 기대효과         ← 패턴 A (마커)
Ⅵ. 추진 일정                    ← 간트차트 테이블
Ⅶ. 기관 현황 및 인력현황         ← 테이블 중심
Ⅷ. 사업비 소요명세              ← 테이블 중심 (금액)
Ⅸ. 기타
```

## 2. 두 가지 섹션 패턴 — 상세 설명

### 패턴 A: 마커 패턴 (□ → 가. → ㅇ)

body_text에 마커 문자만 단독으로 들어있다. 이 마커를 확장하여 풍부한 내용을 작성한다.

**노드 구조:**
```
table_cell: "1"              ← 섹션 번호
table_cell: "추진배경"        ← 섹션 제목
body_text: ""                ← 빈 줄
body_text: "□"               ← 마커 ★ 확장 작성 대상
body_text: ""                ← 빈 줄
body_text: "가."              ← 마커 (확장 or 빈 줄)
body_text: ""                ← skip_fill
body_text: "ㅇ"              ← 마커 (확장 or 빈 줄)
```

**실제 작성 예시 (추진배경):**

"□" 마커 노드에 아래와 같이 작성한다:
```
□ 더스트카버의 출하 공정에서는 육안 검사에서 AI 비전검사 솔루션 도입 필요

ㅇ 자동차 부품 제조업체에서는 제품의 품질 확보가 가장 중요한 요소 중 하나임. 특히 더스트카버(Dust Cover)는 차량의 구동계 및 서스펜션 시스템을 보호하는 중요한 부품으로, 결함이 발생하면 주행 안전성과 내구성에 직접적인 영향을 미칠 수 있음.

ㅇ 현재 더스트카버의 출하 공정에서는 육안 검사와 샘플링 검사를 통해 품질을 관리하고 있으나, 다음과 같은 문제점이 존재
  - 검사 신뢰성 저하 : 육안 검사 방식은 검사자의 숙련도와 피로도에 따라 결과가 달라질 수 있어 불량 검출률이 일정하지 않음
  - 생산 효율성 저하 : 샘플링 검사 방식은 전체 제품이 아닌 일부 제품만을 검사하기 때문에 불량이 출하될 가능성이 있음
  - 불량 유출 리스크 증가 : 표면의 미세한 결함은 기존 검사 방식으로는 검출이 어려워 고객사 납품 이후 클레임이 발생할 가능성이 큼
  - 스마트팩토리 도입 요구 : AI 기반 자동 검사 및 품질 관리 시스템의 도입이 가속화되고 있음

ㅇ 이에 따라, AI 비전검사 솔루션을 도입하여 출하 공정에서의 품질 검사를 자동화하고, 검사 신뢰도를 높이며, 생산성을 향상시키는 것이 필요
```

**"가." 마커 노드 처리:**
- "가." 마커가 □ 마커와 같은 섹션 안에 있으면, □ 에 이미 전체 내용을 넣었으므로 "가." 노드는 빈 문자열("")로 채운다.
- "가." 마커가 독립 소항목이면 해당 소항목 내용을 작성한다.

**"ㅇ" 마커 노드 처리:**
- □ 에 이미 전체 내용을 넣었으면 "ㅇ" 노드도 빈 문자열("")로 채운다.
- 독립 소항목이면 해당 맥락의 1-2문장을 작성한다.

### 패턴 B: 소제목 + 작성요령 + 빈 본문 패턴

소제목이 완전한 텍스트로 존재하고, 작성요령 안내 테이블이 있고, 그 뒤에 빈 body_text가 있다.

**노드 구조:**
```
table_cell: "3"                          ← 섹션 번호
table_cell: "시장 현황"                   ← 섹션 제목
body_text: ""                            ← 빈 줄
body_text: ""                            ← 빈 줄
body_text: "가. 시장 현황"                ← 소제목 (라벨, fills 제외)
table_cell: "< 작성요령 >"               ← 작성요령 표 (fills 제외)
table_cell: "ㅇ 수요기업이 본 과제를..."   ← 안내문 (fills 제외, 참고용)
body_text: ""                            ← ★ 서술 내용 작성 영역 ①
body_text: ""                            ← 빈 줄 (줄 간격)
body_text: ""                            ← 빈 줄
body_text: "나. 시장 동향"               ← 다음 소제목 (라벨, fills 제외)
table_cell: "< 작성요령 >"               ← 다음 작성요령 표
...
```

**처리 규칙:**

1. **소제목 body_text** (예: "가. 시장 현황", "나. 정부지원의 필요성"): **라벨**이다. fills에서 제외하거나 기존 텍스트 그대로 유지한다.

2. **작성요령 테이블의 모든 셀**: fills에서 **제외**한다. 단, 안내 텍스트(예: "ㅇ 수요기업이 본 과제를 제안하게 된 배경...")는 뒤의 빈 body_text에 뭘 써야 하는지 알려주는 **가이드**로 활용한다.

3. **작성요령 직후 첫 번째 빈 body_text**: 여기에 **서술 내용을 작성**한다.
   - □ 마커 없이 바로 ㅇ/- 불릿으로 시작한다
   - 작성요령 안내 텍스트가 지시하는 내용을 충실히 따른다
   - 최소 3-5문단 분량

4. **이후 연속 빈 body_text**: 빈 문자열("")로 둔다 (줄 간격 역할).

**실제 작성 예시 (가. 시장 현황):**

작성요령 직후 첫 번째 빈 body_text에:
```
ㅇ 글로벌 시장 규모
  - 2023년 기준 글로벌 자동차 부품 시장은 약 3조 2천억 달러(USD) 규모로 평가되며, 그중 더스트카버를 포함한 소재·보호 부품 시장은 약 250억 달러 규모로 추정
  - 2030년까지 연평균 4.5% 성장할 것으로 예상되며, 이는 전기차·자율주행차 증가, 친환경 및 고내구성 소재 수요 증가에 기인
  - 특히 아시아·태평양 지역이 40% 이상의 점유율을 차지하며, 중국, 일본, 한국이 주요 생산국으로 자리 잡고 있음

ㅇ 국내 시장 현황
  - 국내 자동차 부품 시장은 약 100조 원 규모이며, 그중 더스트카버를 포함한 차량 보호 부품 시장은 3조 원 이상으로 추산
  - 현대자동차, 기아 등 완성차 업체와 부품 공급사들이 주요 시장 참여자
  - 국내 시장에서는 친환경 소재 적용, 경량화 기술 개발, 고내구성 제품 연구가 활발히 진행되고 있음

ㅇ AI 기반 품질 검사 및 스마트팩토리 도입 증가
  - 자동차 부품 제조업체들은 자동화 및 AI 기반 품질 관리 시스템 도입을 가속화하고 있음
  - AI 비전검사 시스템을 활용하여 미세한 결함을 실시간 검출하고, 데이터 기반으로 품질 개선을 도모하는 사례가 증가
```

**실제 작성 예시 (나. 정부지원의 필요성):**
```
  - 현재 비전검사 시스템을 일부 공정에서 운영하고 있으나, 추가적인 기술 도입과 시스템 확장이 필수적
  - 그러나 AI 비전검사 솔루션의 도입에는 고해상도 카메라, 딥러닝 모델 개발, 데이터 분석 시스템 등 상당한 비용과 기술력이 요구되며, 이를 기업 단독으로 추진하기에는 재정적 부담이 큼
  - 이에 따라, 정부의 지원을 통해 AI 비전검사 솔루션을 도입·확대하고, 제조업의 스마트팩토리 전환을 촉진할 필요
  - 대기업 대비 중소·중견기업은 AI 기술 도입에 대한 초기 투자비용 부담이 커서 도입이 지연되는 경우가 많아 정부 지원을 통해 조기에 도입할 수 있음
```

## 3. 섹션 독립성 원칙 (필수!)

**각 번호 섹션은 독립적이다. 절대 다른 섹션의 마커/빈 노드에 다른 섹션의 내용을 넣지 마라.**

**잘못된 예:**
```
섹션 1 "추진배경"의 □ 마커 → "□ 추진배경 ... 가. 시장 동향 ... 나. 기업 현황 ..."
   ↑ 섹션 3, 4의 내용을 섹션 1에 넣으면 안 됨!
```

**올바른 예:**
```
섹션 1 "추진배경"의 □ → 추진배경 내용만 (현황, 문제점, AI 도입 필요성)
섹션 2 "목적 및 필요성"의 □ → 목적과 필요성만
섹션 3 "시장 현황"의 빈 body_text → 시장 현황 내용 (글로벌/국내 시장 규모, 트렌드)
섹션 4 "기업 현황"의 빈 body_text → 수요기업 비즈니스 현황, 정부지원 필요성
```

**섹션 경계 판별법:**
- 노드 목록에서 **섹션 번호 테이블** (예: `table_cell "3"` + `table_cell "시장 현황"`)이 나오면 새 섹션 시작
- 그 섹션의 내용은 다음 섹션 번호 테이블이 나올 때까지의 노드에만 작성
- **로마 숫자 대제목** (Ⅰ. 개요, Ⅱ. 추진 목표 등)은 대분류 경계

## 4. 섹션별 작성 가이드

### Ⅰ. 개요

#### 1. 추진배경 (패턴 A, 약 1페이지)
- □ 마커에 대제목 + ㅇ 불릿 3-4개
- 첫 ㅇ: 해당 산업/제품의 중요성 설명
- 둘째 ㅇ: 현재 방식의 문제점 나열 (- 하위 불릿 3-5개)
- 셋째 ㅇ: AI 도입 필요성 결론

#### 2. 목적 및 필요성 (패턴 A, 약 1페이지)
- □ 목적 (ㅇ 불릿 3-4개: 구체적 목표)
- □ 필요성 (ㅇ 불릿 3-4개, 각 ㅇ 아래 - 하위 불릿 2-3개)
  - 고품질 요구 대응
  - 생산 효율성 및 원가 절감
  - 스마트팩토리/AI 기술 도입
  - 시장 차별화

#### 3. 시장 현황 (패턴 B)
- **가. 시장 현황** (약 0.5-1페이지): 글로벌 시장 규모, 국내 시장 현황, AI 도입 트렌드
- **나. 시장 동향** (약 0.5페이지): 국내외 주요 기업, 경쟁현황, 기회요소

#### 4. 기업 현황 (패턴 B)
- **가. 수요기업 비즈니스 현황** (약 1-2페이지): 사업 현황, 주요 고객사, 생산 공정, 현재 문제점, 개선 방향
- **나. 정부지원의 필요성** (약 0.5페이지): 기술 도입 비용 부담, 중소기업 한계, 정부지원 당위성

### Ⅱ. 추진 목표

#### 1. 최종 목표 (패턴 B + 테이블)
- **가. 추진내용별 최종 목표**: 테이블 형태 (목표 구분 / 최종 목표 / 세부 목표)
- 5-7개 목표 항목, 각 항목에 세부 목표 2-3개

#### 2. 성과목표 및 성능지표 (테이블)
- **가. 성과목표**: 경제(매출), 기술(특허), 혁신(품질/비용/생산성), 사회(고용/교육) 구분
- **나. 성능지표**: AS-IS vs TO-BE 비교 테이블

### Ⅲ. 컨소시엄 구성 및 역할

#### 1. 컨소시엄 구성/역할 (패턴 A + 테이블)
- □ 마커에 기관별 역할 구분 설명
- 테이블: 구분/기업명/업종/세부역할

#### 2. 기관별 과제 수행 역량 (패턴 B, 각 소항목에 작성요령)
- **1) 주관기관(수요기업)**: 가) AI 솔루션 도입 환경, 나) 데이터 보유 현황, 다) 데이터 추가 수집 계획, 라) 기타 보유역량
- **2) 참여기관(공급기업)**: 가) AI 관련 보유기술 및 성과, 나) 상용화 및 레퍼런스, 다) 인력 및 기타 역량
- 각 소항목: ㅇ 불릿 + - 하위 불릿, 2-4문단

### Ⅳ. 세부 추진 계획

#### 1. 사업 개요 (패턴 A)

## 5. 작성 톤과 수준

### 불릿 구조
- **ㅇ**: 대항목 (2-3줄 완전한 문장)
- **-**: 하위 설명 (1-2줄, ㅇ 아래 들여쓰기)
- 패턴 B 영역에서는 □ 마커 없이 바로 ㅇ 또는 - 로 시작해도 됨

### 분량 기준
- ㅇ 불릿 하나: 최소 1-2줄의 완전한 문장 (단어나 짧은 구절 금지)
- - 하위 불릿: 최소 1줄의 구체적 설명
- 패턴 A의 □ 마커: 최소 10줄 이상의 구조화된 내용
- 패턴 B의 빈 body_text: 최소 8줄 이상

### 정량적 수치 활용
실제 선정 제안서에서 사용된 수치 표현 패턴:
- 시장 규모: "약 3조 2천억 달러(USD) 규모", "약 100조 원 규모"
- 성장률: "연평균 4.5% 성장", "연평균 42.3% 성장"
- 점유율: "40% 이상의 점유율"
- 품질 목표: "불량 검출 정확도 99% 이상", "불량률 30% 감소"
- 비용 효과: "검사 속도 300% 향상", "비용 40% 절감"
- 고용: "정규직 1명 신규 고용", "상용직 2명 신규 고용"

### 전문성
- 해당 산업의 전문 용어 적극 활용 (MES, ERP, WMS, SOP, CNN, YOLO 등)
- "~임", "~함", "~있음" 체 사용 (경어체 아님)
- 구체적 제품명, 기술명, 기업명을 포함하여 현실감 있게 작성

## 7. 특수 셀 처리

### 큰 셀의 안내 텍스트 ("*"로 시작)
요약서-2 등에서 `* 과제의 목표 및 과제수행결과 창출되는 결과물의 수준 등에 대하여...` 같은 안내 텍스트가 있는 큰 셀은:
- 안내 텍스트를 **삭제하고 실제 내용으로 교체**
- 안내 텍스트의 지시에 따라 작성

### 목차 셀 (167x156mm)
목차는 실제 섹션 구조에 맞게 작성한다. 페이지 번호는 추정치로 넣는다.

### 서약서/제출문 셀 (168x119mm)
큰 셀에 서약 문구 + 날짜 + 기관장 서명란이 있다. 날짜와 기관장명을 채운다.

### 용역계획서
용역 계획이 없으면 "해당없음"으로 작성한다.
